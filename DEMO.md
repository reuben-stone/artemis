# Artemis — Demo Overview

**Artemis** (Autonomous Repository-Tending Engineering, Monitoring & Intelligence System) is a Claude-powered AI operations layer that runs as a persistent desktop app, giving developers a single intelligent interface across their entire codebase ecosystem. Rather than answering one-off questions, Artemis acts as a named operator with a voice, a reactive 3D orb presence, and a built-in terminal — it monitors multiple repositories at once, delivers cross-repo morning briefings (git status, recent activity, and live Google Analytics metrics in a single command), and dispatches autonomous worker agents that tackle fix-it tasks in isolated git worktrees, run the repo's own checks, and open gated pull requests for human review without ever touching a protected branch. Conversations and in-flight work survive restarts thanks to a SQLite-backed transcript and git-tracked memory store, while a swappable `ModelClient` seam lets Artemis route turns to the Anthropic API, a local Ollama model, or the Claude subscription CLI — all configured through a point-and-click Connections panel. This demo PR was created automatically by the worker dispatch system to showcase end-to-end task execution.
